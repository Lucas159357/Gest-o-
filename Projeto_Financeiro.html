Sobre o armazenamento

Os registros são salvos localmente no navegador. Os comprovantes anexados ficam no banco de dados do navegador (IndexedDB), que comporta bem mais que o armazenamento comum, e entram no backup JSON. Faça backups frequentes.

Limpar os dados do navegador pode apagar seus registros e anexos. O backup JSON inclui os anexos para restauração.
